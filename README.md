# ghostbie
ghostbie is a tiny motion-controlled digital pet like a desktop Tamagotchi with minimal gameplay buttons. Instead of pressing controls, you interact with it by physically moving the board.

#What it is
ghostbie is designed to sit on your desk its basic goal is to entertain you and be super cute
The board includes a microcontroller, display, motion sensor, and environmental sensor in a compact PCB design. It is USB powered and built around beginner-friendly through-hole soldering for the add-on components.
